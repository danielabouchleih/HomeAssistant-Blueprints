# 🏠 My Home Assistant Config & Automations

Willkommen in meinem Repository für **Home Assistant Automationen, Blueprints und Konfigurationen**. Hier sammle, entwickle und strukturiere ich meine Smart-Home-Logiken, um mein Zuhause intelligenter und automatisierter zu gestalten.

## 📁 Repository-Struktur

Das Repository ist wie folgt aufgebaut:

*   📂 **`automations/`** – Maßgeschneiderte YAML-Automationen für Licht, Klima, Sicherheit und mehr.
*   📂 **`blueprints/`** – Wiederverwendbare Automatisierungsvorlagen (eigene & modifizierte).
*   📂 **`scripts/`** – Skripte für komplexe Abfolgen und Szenen-Steuerungen.
*   📂 **`templates/`** – Template-Sensoren und Helfer-Konfigurationen.

## 🚀 Highlights & Kern-Features

*   ⚡ **3D Druck:** Fortschritts-Benachrichtigung via Live Activity für HA Companion App

## 🛠️ Installation & Nutzung

Wenn du Teile dieser Konfiguration in deinem eigenen Home Assistant nutzen möchtest:

1. Klicke oben rechts auf **Code** und downloade das Repository oder klone es via Git:
   ```bash
   git clone https://github.com
   ```
2. Kopiere die gewünschten YAML-Dateien in deinen entsprechenden Home Assistant Ordner (z. B. `/config/automations/`).
3. Ersetze die Entitäten-IDs (`entity_id`) durch deine eigenen Geräte-IDs.
4. Starte die Home Assistant Konfiguration neu oder lade die Automationen neu.
